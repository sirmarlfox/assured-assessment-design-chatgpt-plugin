# ChatGPT description and conversation starters

## Name

Assured Assessment Design

## Description

An adaptation of the Claude skill for educators designing assured assessment. Consults on your situation, checks current guidance and develops inclusive supervised or interactive options, with assurance ratings, staffing maths and a practical plan.

## Conversation starters

1. Help me redesign a take-home assessment while keeping an in-person endpoint.
2. My students use an IT lab without locked-down computers. How can I assure their learning?
3. I have a large cohort and limited staff time. Help me find workable assessment options.
4. Quick mode: help me choose three assessment formats for my cohort, learning outcomes and available rooms.

The native plugin manifest exposes the first three because the format supports up to three launch prompts. The fourth is retained here for copy and paste, or for an existing GPT editor that supports four.

## Capabilities

Use a session with web search enabled for Step 0. If search is unavailable, the plugin must disclose this and use the source-registry baseline dated 24 November 2026. This setting cannot be forced by a skills-only plugin archive.
